# 🌍 Navora AI – Smart AI Trip Planner

Navora AI is an intelligent travel planning platform that helps users create personalized travel itineraries based on their destination, budget, travel duration, and preferences. It combines AI-powered recommendations with real-time travel information to simplify trip planning.

---

## 🚀 Features

- 🗺️ AI-generated personalized travel itineraries
- 📍 Destination search
- 💰 Budget-based trip planning
- 🏨 Hotel recommendations
- 🌦️ Live weather information
- 📅 Day-wise itinerary generation
- 📊 Expense calculator
- 🗺️ Google Maps integration
- 📄 Download trip plan as PDF
- 🌙 Dark/Light mode
- 🔐 User Login & Authentication
- 📱 Fully responsive modern UI

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/yourusername/Navora-AI.git
```

```bash
cd Navora-AI
```

---

## Frontend Setup

```bash
cd frontend
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

---

## Backend Setup

```bash
cd backend
```

Create a virtual environment

```bash
python -m venv venv
```

Activate it

Windows

```bash
venv\Scripts\activate
```

Linux / macOS

```bash
source venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run Flask server

```bash
python app.py
```
